# BEAMpi

Set up and control Raspberry Pis from a Mac or PC, by BEAM Events: write Raspberry Pi OS cards with the login, Wi-Fi and IP already set, then change the IP address, Wi-Fi, hostname, reboot, update and run your own command presets over SSH.

Download the latest version from [Releases](../../releases/latest).

- **Mac**: the `.dmg`. The first time, right-click BEAMpi → **Open**.
- **Windows**: `BEAMpi-Setup-….exe` (updates itself) or the Portable `.exe`. Writing SD cards is Mac-only for now.

Installed copies update themselves from this page.
